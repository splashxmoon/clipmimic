01 / Inspect the creative structure

Reference video analysis.
A blueprint you can read.

  1. 01

    Analyze a reference

    Start with a rights-cleared file or supported URL. Detect scene cuts, shot durations, pacing and aspect. Optionally extract keyframes.

  2. 02

    Inspect the Style Blueprint

    Keep the structure in versioned JSON with schemaVersion: "1.0". Review the boundaries: scene detection is a heuristic.

  3. 03

    Write a new topic

    Mimic turns the blueprint and your topic into per-shot prompts. Add brand or style cues. Prompt planning makes no Replicate calls.

  4. 04

    Optionally generate

    Add --generate to submit paid Replicate jobs. Check each job, select the outputs and assemble your final edit manually.

The hand-off

Structure, made portable.

A blueprint is a starting point for your creative decisions. It does not understand a scene’s meaning or recreate the reference’s content.

Read the Blueprint contract ↗
{
  "schemaVersion": "1.0",
  "aspect": "9:16",
  "shots": [
    { "index": 0, "startSec": 0,
      "endSec": 2, "durationSec": 2 }
  ]

Illustrative excerpt, not a complete blueprint or measured result. Source aspect and timing inform prompts; they do not guarantee generated dimensions or duration.

03 / Start local, render when ready

Install the Claude Code skill.

Node.js 18+ and Claude Code. Analysis needs ffmpeg and ffprobe; URLs also need yt-dlp. No npm dependencies to install. Replicate rendering requires an account and token and costs money.

Plugin installation

/plugin marketplace add splashxmoon/clipmimic
/plugin install clipmimic@clipmimic

The plugin is named clipmimic, so commands appear as /clipmimic:analyze and so on. Keep the full plugin checkout, including its skill link.

Project-copy installation

From a repository checkout, copy both the skill and slash-command wrappers into your project:

mkdir -p /path/to/project/.claude/skills
cp -R .claude/skills/video-generation /path/to/project/.claude/skills/
cp -R .claude/commands /path/to/project/.claude/

Keep scripts and libraries together. Wrappers use project-relative paths; this copy recipe is for a project, not ~/.claude. Merge carefully if your project already has commands.

Analyze. Inspect. Plan.

Start without provider charges. To save keyframes, add --keyframes frames to analysis.

/clipmimic:analyze ref.mp4 --out blueprint.json
/clipmimic:mimic blueprint.json --topic "A refillable water bottle launch"
Optional paid AI video generation

Set the token in the environment used by Claude Code. Never commit it. Check your chosen model’s current inputs and pricing, and count the shots before submitting.

export REPLICATE_API_TOKEN="your-token-here"
/clipmimic:mimic blueprint.json --topic "A refillable water bottle launch" --generate
/clipmimic:status <job-id>

--generate submits a job per shot and prints IDs; it does not assemble an edit. Model availability varies. Prompts request timing and aspect, but generation settings and outputs require your review.

Need direct Node commands or troubleshooting? See the full README quickstart. The skills CLI route is not yet a verified public installation.

05 / Before your first cut

A few useful answers.

Can ClipMimic mimic viral videos or make a UGC ad clone?

ClipMimic can reuse a reference’s timing and structural cues to plan new shots. It does not copy footage, scripts, music or likeness, and it cannot guarantee identical visuals, virality or ad performance.

Which reference videos can I use?

Use footage you own or have permission to access and use for your purpose. Follow platform terms and relevant rights. A public URL is not a license; do not bypass private accounts, DRM or access restrictions.

Is AI video generation free?

The JavaScript code is MIT licensed. Local analysis and prompt-only mimic do not call Replicate. Replicate rendering is paid and each shot or retry can add costs. Claude Code may have separate costs. No free inference credits are included.

What is a Style Blueprint?

A Style Blueprint is JSON with schemaVersion "1.0" that records shot boundaries, durations, pacing and aspect ratio, with optional keyframes. It is structural analysis, not a transcript or a vision-generated scene description.

Does it export finished TikToks, Reels or Shorts?

No. ClipMimic produces per-shot prompts and can optionally submit individual Replicate jobs. Review the outputs, set the final aspect ratio, assemble clips, add audio or captions and apply platform disclosures yourself.
