# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be respectful, assume good faith, and keep discussion focused on the work.

Report unacceptable behavior to the maintainers by opening a private security advisory or emailing the address listed in `SECURITY.md`. Maintainers will review and respond promptly.
