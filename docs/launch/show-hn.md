Suggested title concept: `Show HN: clipmimic – reference-inspired video workflows in Claude Code`

Destination: `https://github.com/splashxmoon/clipmimic` after a usable tagged release exists.

Human author: write a short personal introduction covering:

1. What you were making and why switching between reference analysis and generation was awkward. Include a real experience, not an invented founder story.
2. What users can try today. Verify analyze/mimic in the release: scene-cut/pacing/keyframe analysis → Style Blueprint → new-topic shot prompts → optional Replicate generation. Mention the four core generation/status/model commands if relevant.
3. What the demo actually did: `<demo URL>`, `<model/version>`, `<elapsed time>`, `<billed cost>`, `<retries>`, and whether editing was manual. Leave no placeholders in the submitted text.
4. Requirements: Claude Code, documented Node version, ffmpeg/ffprobe for analysis, yt-dlp for supported URLs, and a paid provider account for rendering. Identify a no-token example/dry-run only if it works.
5. Limits: no transcript extraction, semantic vision descriptions or automatic final assembly unless subsequently shipped. Reference structure is inspiration; original footage/music/likeness are not copied. No performance guarantee.
6. One precise technical question, such as whether the blueprint is detailed enough to reproduce pacing in another generation backend.

Be available to explain implementation tradeoffs, failed outputs and the open-source license. No claims of popularity, costs or quality without measurements.
